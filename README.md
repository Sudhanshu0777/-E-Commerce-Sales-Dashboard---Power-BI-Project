📊 Overview
This Power BI dashboard presents a comprehensive analysis of an e-commerce company's sales performance over the course of one year, segmented quarter-wise. It offers deep insights into sales amount, profit, quantity sold, and average order value (AOV) across different states, customers, product categories, sub-categories, and payment modes.

🎯 Purpose
The goal of this project is to demonstrate skills in data modeling, visualization, and interactive reporting using Power BI. It helps business stakeholders quickly understand:

Where most sales are coming from.

Which customers are most valuable.

How different products are performing.

Which months or quarters need attention.
